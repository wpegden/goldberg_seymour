\begin{definition}
For the active Part I index set \(L\) and a vertex \(w\), the support
class of \(w\) is
\[
                 L(w)=\{s\in L:v_s=w\}.
\]
Thus the nonempty sets among the \(L(w)\) are exactly the manuscript's
classes \(L_1,\ldots,L_\kappa\): two active PE indices lie in the same
class precisely when their exact chosen supporting vertices agree.
\end{definition}

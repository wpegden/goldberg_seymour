\begin{definition}
For a displayed tree-sequence (T) and a vertex (v\in V(T)), let
(V(T(v)-v)) be the finite set of displayed vertices strictly preceding
(v) in the order of (T).  Thus
\[
 V(T(v)-v)=\{w\in V(T):w\prec_T v\}.
\]
This definition also applies when (v) is one of the first displayed
vertices, in which case the set may contain no edge-bearing tree-sequence.
\end{definition}

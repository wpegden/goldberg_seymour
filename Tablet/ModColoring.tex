\begin{definition}
Let \(T\) be an extended Tashkinov tree with rung number \(n\), terminal
ladder stage \(T_n\), generating coloring \(\varphi_n\), final extension
kind \(\Theta_n\), and exact connecting-edge set \(F_n\).  A coloring
\(\sigma_n\) is a \(\varphi_n\bmod T_n\) coloring if it is proper and
leaves exactly the distinguished edge uncolored, and the following
universal condition holds.

For every ordered tree-sequence \(T^*\) strictly extending \(T_n\):
if \(\Theta_n=PE\), require that \(T^*\) be obtained from \(T_n\) by TAA
under \(\sigma_n\); if \(\Theta_n\) is \(SE\) or \(RE\), require that
there be an edge identity \(f_n\) with the exact equality
\(F_n=\{f_n\}\), that one first form the exact one-edge extension
\(T_n+f_n\), and that \(T^*\) then be obtained from this seed by TAA under
\(\sigma_n\).  Every \(T^*\) satisfying the appropriate condition must
carry a corresponding-ETT certificate for \((\sigma_n,T_n)\).  Thus this
definition ranges over every eligible nondeterministic TAA extension; it
does not select one extension by choice.
\end{definition}

\begin{definition}
In the extension-base setting, let \(L\) be the active PE-index set from
\noderef{ExtensionBaseActiveIndices}, let \(v_n\) be the terminal
supporting vertex, and let \(L_1=L(v_n)\) be its support class from
\noderef{ExtensionBaseSupportClass}.  Define the restoration-index set
by
\[
                         L^*:=L\setminus L_1.
\]
Thus \(L^*\) retains the identities of all active PE slots supported at
vertices other than \(v_n\); it is a finite set of certified series
indices, not merely a set of color pairs.
\end{definition}

\begin{lemma}[Revisiting certificates are invariant on old slots]
Let \(A^+\) be obtained by appending arbitrary final values to Tashkinov-series
data \(A\) as in \(\noderef{TashkinovSeriesDataAppend}\), and let \(i\) be an
old index.  Every revisiting-extension certificate for \((A^+,i^+)\) induces
one for \((A,i)\), and every certificate for \((A,i)\) induces one for
\((A^+,i^+)\).  In either direction the induced certificate has exactly the
same ordered gamma and delta, the same connecting edge identity, and the same
named inside and outside endpoints as the certificate from which it was
induced.
\end{lemma}
\begin{proof}
Consider first a certificate \(C^+\) for the appended data.  Its earlier index
\(h\) satisfies \(h\leq i^+\), hence
\(h.val\leq i.val<r+1\).  Define the old index
\(h_0=\langle h.val,h.val<r+1\rangle\); then \(h=h_0^+\).  The old-slot
equations in \(\noderef{TashkinovSeriesDataAppendEquations}\) identify the PE
kind and ordered gamma and delta at these two indices.  For every old
\(j\) strictly between \(h_0\) and \(i\), apply the intervening-RE clause of
\(C^+\) to \(j^+\); its kind is the old kind by the same equations.

The current coloring, the earlier tree, and the current tree in \(C^+\) are
respectively equal to the old current coloring, old earlier tree, and old
current tree.  For the current tree, note explicitly that
\((i^+).succ=(i.succ)^+\); for the earlier tree use \(h=h_0^+\).
Transport the following dependent package simultaneously across those three
equalities: the exact two-color cycle, its earlier and outside intersections,
the selected edge's membership in the cycle and current boundary, the two
endpoint membership clauses, the return vertex, the exact return walk, its
path property, its inclusion in the cycle, and its current-tree internality.
Simultaneous transport is essential because the walk types depend on the
coloring and their support clauses depend on the transported walks.  Together
with the unchanged endpoint equation, this package and the converted history
fields form a certificate \(C\) for \((A,i)\).  Its gamma, delta, edge,
inside endpoint, and outside endpoint were installed directly from \(C^+\),
so the five asserted equalities are reflexive.

For the reverse direction, map the earlier old index \(h\) to \(h^+\).
An enlarged index \(j\) occurring in the intervening-RE clause is bounded by
\(i^+\), so the numerical argument above converts it to a unique old
\(j_0\) with \(j=j_0^+\); the old intervening clause supplies the required
RE kind.  Use the old-slot equations again to identify the current coloring,
earlier tree, and current tree, and transport the complete cycle-and-return-
path package together in the opposite direction.  This yields a certificate
for \((A^+,i^+)\), again installing the original gamma, delta, exact edge,
and two endpoints verbatim.  Hence both witness-preserving maps exist.
\end{proof}

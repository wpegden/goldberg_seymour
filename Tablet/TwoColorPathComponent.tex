\begin{definition}
Fix two distinct colors \(\alpha,\beta\) and a partial edge coloring \(\varphi\).
The two-color path component through an incidence-graph node \(z\) is the
connected component of \(z\) in the bipartite incidence graph on
\(V(G)\sqcup E(G)\), restricted to edges colored \(\alpha\) or \(\beta\),
provided that the component has a node with at most one neighbor.  Thus an
isolated vertex component counts as a path, exactly as in the paper's
two-color-chain convention; the leaf condition distinguishes path
components from alternating cycle components.  Graph-edge nodes, when
present, are the actual elements of \(E(G)\), so distinct parallel edges
remain distinct in this definition.
\end{definition}

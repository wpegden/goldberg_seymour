\begin{definition}
Fix two distinct colors \(\alpha,\beta\) and a partial edge coloring \(\varphi\).
The two-color path component through an incidence-graph node \(z\) is the
connected component of \(z\) in the bipartite incidence graph on
\(V(G)\sqcup E(G)\), restricted to edges colored \(\alpha\) or \(\beta\),
provided that the component contains at least one genuine edge node and
has a node with at most one neighbor.  The first condition excludes
isolated unused vertices, and the second distinguishes path components
from alternating cycle components.  Because graph-edge nodes are the
actual elements of \(E(G)\), distinct parallel edges remain distinct in
this definition.
\end{definition}

\begin{lemma}[Equations for appending Tashkinov-series data]
For the appended data of \(\noderef{TashkinovSeriesDataAppend}\), every old
tree slot at its canonical cast-successor index is exactly the old tree, and
the last tree slot is exactly the supplied new tree.  At every canonical old
non-tree slot, the coloring, stored-color set, connecting-edge set, extension
kind, chosen vertex, outside vertex, delta, and gamma are respectively equal
to their old values.  At the last non-tree slot those eight fields are
respectively equal to the eight supplied new values.
\end{lemma}
\begin{proof}
By \(\noderef{TashkinovSeriesDataAppend}\), each of the nine arrays is a
last-index case split.  Applying that split to a cast-successor index selects
the old-array branch, while applying it to the last index selects the supplied
terminal-value branch.  The two computation rules for last-index case
analysis therefore give the asserted tree equations and, field by field, all
sixteen non-tree equations.  No coercion changes an index value in a
cast-successor branch, so each equality is literal rather than merely an
isomorphism of arrays.
\end{proof}

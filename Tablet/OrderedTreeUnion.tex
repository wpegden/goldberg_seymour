\begin{definition}
Let $A,B$ be tree-sequences with the same distinguished first edge.  An
\emph{ordered tree union} $A\vee B$ is a tree-sequence $U$ with the
following data and properties.
First, $A$ is an ordered initial segment of $U$, and
$V(U)=V(A)\cup V(B)$.  Every displayed entry of $U$ added after $A$ is
an exact edge--new-vertex entry of $B$, and every entry of $B$ whose new
vertex is outside $A$ occurs in this added part.  Finally, the relative
order of those new entries in $U$ is the same as their relative order in
$B$.  All equalities are equalities of individual edge identities, so the
construction retains distinct parallel edges.
\end{definition}

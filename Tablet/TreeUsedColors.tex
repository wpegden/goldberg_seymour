\begin{definition}
A color is used on a tree-sequence
$T=(y_0,e_1,y_1,\ldots,e_n,y_n)$ under $\varphi$ if it colors one of the
colored tree-edge identities $e_2,\ldots,e_n$.  The first edge $e_1=e_0$
is excluded because it is the distinguished uncolored edge in a
$k$-triple.  The set of all such colors is denoted $\varphi\langle T\rangle$.
\end{definition}

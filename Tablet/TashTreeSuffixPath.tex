\begin{definition}
Let
\(T=(y_0,e_1,y_1,\ldots,e_n,y_n)\) be a tree-sequence.  A natural
number \(q\) is a suffix-path start for \(T\) if \(1\le q\le n\) and,
for every \(q\le i<n\), the exact edge identity \(e_{i+1}\) has endpoints
\(y_i,y_{i+1}\).  Equivalently, the displayed suffix
\[
 y_q,e_{q+1},y_{q+1},\ldots,e_n,y_n
\]
is a graph path in its displayed order.  This definition concerns exact
edge identities, so parallel edges are not identified.
\end{definition}

\begin{definition}
For a fixed distinguished edge identity $e_0$ and coloring $\varphi$, a
Tashkinov tree $T$ is fixed-pair maximal if no Tashkinov tree $S$ for that
same pair has a strictly larger vertex set containing $V(T)$.  Equivalently,
whenever $V(T)\subseteq V(S)$ for such an $S$, one also has
$V(S)\subseteq V(T)$.
\end{definition}

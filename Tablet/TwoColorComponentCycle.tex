\begin{definition}
For a partial edge coloring \(\varphi\), two colors \(\alpha,\beta\),
and a vertex or edge node \(z\) of the two-color incidence graph, the
\((\alpha,\beta)\)-component through \(z\) is a cycle if there is a
simple closed two-color walk whose support, including both its vertex nodes
and its individual edge nodes, is exactly the connected component through
\(z\).  Requiring equality with the whole component rules out a cycle with
an additional path attached to it.
\end{definition}

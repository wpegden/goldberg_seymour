\begin{definition}
For a displayed tree-sequence \(T\), colors \(\alpha,\beta\) are
\(T\)-interchangeable under a coloring \(\varphi\) if any two
\((\alpha,\beta)\)-path components in the incidence-based two-color graph
that each contain a vertex of \(T\) are the same connected component.
Equivalently, at most one such two-color path component meets \(T\), with
an isolated vertex component counted as a path.
Component equality is equality in the incidence graph, so parallel edge
identities are not collapsed.
\end{definition}

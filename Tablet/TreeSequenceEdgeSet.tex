\begin{definition}
For a tree-sequence
$T=(y_0,e_1,y_1,\ldots,e_p,y_p)$, its displayed edge set is
\[
 E(T)=\{e_i:1\leq i\leq p\}.
\]
The set contains the actual edge identities occurring in the ordered
sequence, including the distinguished first edge; parallel edges are not
identified merely because they have the same endpoints.
\end{definition}

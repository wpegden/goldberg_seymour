\begin{definition}
For a hierarchy with terminal tree $T=T_{n,q+1}$, define
\[
 D_{n,q+1}=D_n-\overline{\varphi_n}(T).
\]
Equivalently, it is the union of the stored sets $S_h$ through the
terminal rung with all colors missing on $T$ removed.  This is the
terminal stored-color set used in the last clause of
\textup{LEM\_Stable}.
\end{definition}

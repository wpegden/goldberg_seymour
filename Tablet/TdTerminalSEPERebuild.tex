\begin{helper}[Terminal SE and PE reconstruction]
Let (T) be a positive-rung extended Tashkinov tree generated by
\[
 \mathcal T=\{(T_i,\varphi_{i-1},S_{i-1},F_{i-1},\Theta_{i-1}):
                   1\leq i\leq n+1\},
\]
and suppose that (T) has the maximum property.  Keep the graph (G),
palette size (k), and distinguished uncolored edge (e_0) fixed, but
allow the certified input coloring to vary arbitrarily.  Assume explicitly
the following six assertions for every positive-rung ETT (T') on these
fixed data, with arbitrary certified input coloring \(\varphi'_0\), maximum
property, and rung number (s<n), writing \(\varphi'_s\) for its generating
coloring and \(\mathcal T'\) for its certified series:
\begin{enumerate}
\item (V(T')) is elementary with respect to \(\varphi'_s\).
\item Under every proper \((T'_{s+1},D'_s,\varphi'_s)\)-stable coloring
leaving precisely (e_0) uncolored, (T'_{s+1}) is interchangeable for
any pair of colors of which at least one is missing on (T'_{s+1}).
\item For each PE slot (a\leq s) with supporting vertex (u_a) and
(m(u_a)=b), every proper \((T'_a,D'_a,\varphi'_a)\)-stable coloring
leaving precisely (e_0) uncolored is
\((T'(u_a)-u_a,D'_{b-1},\varphi'_{b-1})\)-stable.  When (b>1), it is
also \((T'_{b-1},D'_{b-1},\varphi'_{b-1})\)-stable.  Moreover, the stored
color pairs at two distinct PE slots with distinct supporting vertices
and the same first-appearance index are disjoint.
\item If the terminal slot is PE with supporting vertex (u_s) and
stored colors \(\gamma'_s,\delta'_s\), then under every proper
\((T'_s,D'_s,\varphi'_s)\)-stable coloring leaving precisely (e_0)
uncolored, the \((\gamma'_s,\delta'_s)\)-component through (u_s)
contains exactly the one vertex (u_s) of (T'_s).
\item If \(\tau\) is any proper \((T'_s,D'_s,\varphi'_s)\)-stable
coloring leaving precisely (e_0) uncolored, (d) is defective on
(T'_s) under \(\tau\), and (x) is a nonminimum vertex of
\(I[\partial_{\tau,d}(T'_s)]\), then
(x\preceq_{T'}u_a) for every PE supporting vertex or SE extension
vertex (u_a) with (m(x)\leq a\leq s).
\item Every proper \((T'_s,D'_s,\varphi'_s)\)-stable coloring leaving
precisely (e_0) uncolored is a \(\varphi'_s\bmod T'_s\) coloring.
\end{enumerate}

Assume in addition that the terminal extension kind is SE or PE.  Then every proper \((T_n,D_n,\varphi_n)\)-stable coloring \(\sigma_n\)
leaving precisely (e_0) uncolored is a
\(\varphi_n\bmod T_n\) coloring in the sense of
\(\noderef{ModColoring}\).  In particular, the conclusion is universal
over every eligible ordered tree-sequence strictly extending (T_n),
and not merely over one selected closure.
\end{helper}
\begin{proof}
Fix the stable terminal coloring and an arbitrary eligible strict extension.
The exact predecessor package from \noderef{TdReplacementPrefixExact}
constructs the replacement series through T_n, including the direct initial
closure when n=1.  In the PE branch it uses the inverse component switch and
the one-vertex intersection supplied by current assertion (iv); in the SE
branch the preterminal and terminal colorings coincide.  In either case the
preterminal coloring is proper, leaves exactly e_0 uncolored, is stable over
D_{n-1}, and the copied old closure ends at the exact tree T_n.

For every earlier PE slot compare the two constructors with
\noderef{TdEarlierPEWitnessIdentification}.  Singleton connecting-edge
agreement identifies the edge itself, inside/outside membership orients its
endpoints, and the post-switch missing/present test orients the two stored
colors.  Hence the support vertex, outside endpoint, delta, and gamma agree
slot by slot, without any uniqueness assumption on internal constructor
witnesses.

Keep the old maximum-defective edge f_n and vertex v_n.  Stability preserves
the complete delta_n-colored boundary set by exact edge identity and preserves
all vertex missing sets.  Therefore the old defective edge, its incidence,
outside endpoint, and color remain valid.  For any further coloring stable
over D_{n-1}, transitivity of stability makes it admissible for the old
maximum-defective choice, so the old universal order maximality proves the new
one.  The selected defective color has two distinct boundary identities;
thus the closed tree T_n is not strongly closed.

For SE, enlarged stability transports the old universal disjointness
alternative.  For PE it transports the old counterexample to disjointness.
In the PE branch, the same gamma is missing at v_n.  If the old history rule
points to its latest earlier PE slot, the slotwise identification above
preserves both its support and delta and also preserves latestness.  If no
earlier PE used v_n, the converse identification rules out such a replacement
slot.  This proves the full history-sensitive
\noderef{ParallelExtensionColor} condition.

In PE, use the preterminal coloring as the second stable coloring.  The
switched component has unchanged support and meets T_n only at v_n; properness
and degree at most two make it the required exit path.  Involutivity of the
component transposition gives the exact terminal coloring equation.  In SE
that equation is equality.

Finally suppose a revisiting certificate existed for the replacement prefix.
Its all-RE intervening history transports to the original prefix.  Copy its
controlled return path edge by edge back to the original preterminal coloring.
The copied component differs from the persisted original PE exit component at
the return vertex.  If it were a path, lower-rung interchangeability would be
violated; hence it is a cycle and reconstructs an original revisiting
certificate, contradicting the old no-RE field.  Thus priority is preserved.

All SE or PE constructor fields are now available.  Append that constructor
to the exact prefix and compose the eligible route through the arbitrary
extension with a closure.  The resulting series gives a
\noderef{CorrespondingExtendedTashkinovTree} for that extension with every
exact edge identity retained.  Since the extension was arbitrary, the
universal clause of \noderef{ModColoring} follows.
\end{proof}

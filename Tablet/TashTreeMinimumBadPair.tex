\begin{definition}
A bad pair \((\varphi,T)\) from \noderef{TashTreeBadPair} is a minimum bad
pair if no bad pair \((\psi,S)\), for any proper partial \(k\)-coloring
\(\psi\) leaving the same exact edge \(e\) uncolored, has smaller rank in
the sense of \noderef{TashTreeRankLess}.  Thus the minimum is taken over
both the generating coloring and the displayed Tashkinov tree, exactly as
in the registered proof.
\end{definition}

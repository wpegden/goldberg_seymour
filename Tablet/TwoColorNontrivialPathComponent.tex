\begin{definition}
For distinct colors \(\alpha,\beta\), a two-color path component through
an incidence-graph node \(z\) is nontrivial if it is a
\noderef{TwoColorPathComponent} and its full
\noderef{TwoColorComponent} contains the node of at least one actual
multigraph edge.  This is precisely the edge-bearing subclass of the
paper's path components; it excludes isolated vertices while preserving
the identities of parallel edges.
\end{definition}

\begin{lemma}[Scheide enlarged set is elementary (16)]
For a replacement family, the enlarged set
$X=V(T)\cup\bigcup_\delta U_\delta$ is elementary with respect to
$\varphi$.
\end{lemma}
\begin{proof}
By \noderef{ScheideReplacementAbsorbing}, every vertex in every
$U_\delta$ belongs to \noderef{AbsorbingVertices}$(T,\varphi)$.  Therefore
the finite union \noderef{ScheideEnlargedVertexSet} is a subset of
$V(T)\cup A(T,e_0,\varphi)$.  The latter set is elementary by
\noderef{ScheideAbsorbingElementary}.  Pairwise disjointness of missing
color sets passes to subsets, so $X$ is elementary.
\end{proof}

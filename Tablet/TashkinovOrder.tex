\begin{definition}
For a finite multigraph $G$, put $k=\chi'(G)-1$.  The Tashkinov order
$t(G)$ is the largest cardinality $|V(T)|$ among all choices of an edge
identity $e_0$, a partial coloring $\varphi$, and a Tashkinov tree $T$ for
which $(G,e_0,\varphi)$ is a $k$-triple.  The maximum is taken over the
finite set of attainable cardinalities between $0$ and $|V(G)|$; its value
is defined to be $0$ if there is no such triple.
\end{definition}

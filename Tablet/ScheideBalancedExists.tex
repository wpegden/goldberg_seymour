\begin{lemma}[Balanced triples, part (c); Scheide Lemma 3.12(c)]
If $G$ has a globally maximum triple, then $G$ has a balanced globally
maximum triple.  Equivalently, the class $\mathcal T^B(G)$ is nonempty.
\end{lemma}
\begin{proof}
By \noderef{ScheideNormalisation}, the finite class of normal globally
maximum triples is nonempty.  Choose one whose height is maximum.  By the
definition \noderef{ScheideGraphHeight}, its height is $h(G)$.  Apply
\noderef{ScheideBalancedFromMaxNormal} to this maximum-height normal
triple.  The resulting tree and the same fixed pair form a balanced
globally maximum triple, as required.
\end{proof}

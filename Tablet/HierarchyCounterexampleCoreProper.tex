\begin{lemma}[The parallel base is proper in a counterexample]
Let $T$ be a hierarchy counterexample.  If its starred base
$T_{n,0}^{*}$ is elementary under the generating coloring, then
$T\ne T_{n,0}^{*}$.
\end{lemma}
\begin{proof}
By \noderef{HierarchyCounterexample}, $V(T)$ is not elementary under the
generating coloring.  If $T=T_{n,0}^{*}$ as ordered tree-sequences, their
vertex sets are equal, so the assumed elementarity of the starred base
would make $V(T)$ elementary.  This contradicts the counterexample
condition and proves the strict inequality.  In the PE case,
\noderef{HierarchyBase} identifies this starred base with
$T_n\vee R_n$, so this is exactly the reduction (5.3).
\end{proof}

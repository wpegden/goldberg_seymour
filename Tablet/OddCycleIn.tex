\begin{definition}
An odd cycle of $G$ contained in a vertex set $X$ consists of an odd number
$n\geq3$ of pairwise distinct cyclically ordered vertices
$x_0,\ldots,x_{n-1}$ in $X$ and pairwise distinct edge identities
$f_0,\ldots,f_{n-1}$, where $f_i$ has ends $x_i$ and
$x_{i+1\pmod n}$.  We write that $G[X]$ contains an odd cycle when such
data exist.  Keeping the edge map injective preserves the identities of
parallel edges.
\end{definition}

\begin{definition}
A \emph{reduced Scheide structural configuration} is a Scheide structural
configuration in which the number of blocks equals the number of exit
vertices, every exit vertex misses exactly one of the indexed block colors,
and every indexed block color is missing at an exit vertex.  Thus sending an
exit vertex to its unique missing block color is a bijection, with the
indexed colors retaining their distinct identities.
\end{definition}

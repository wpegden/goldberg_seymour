\begin{definition}
Let $T_{n,j}^{*}$ be a starred stage of a hierarchy.  A coloring
$\sigma_n$ is \emph{$(T_{n,0}^{*},D_n,\varphi_n)$-weakly stable} if it
is $(T_n\oplus R_n,D_n,\varphi_n)$-stable when $\Theta_n=PE$, and is
$(T_n,D_n,\varphi_n)$-stable otherwise.  For $1\leq j\leq q$, it is
\emph{$(T_{n,j}^{*},D_n,\varphi_n)$-weakly stable} if it is weakly
stable at the starred base and is additionally
$(T_{n,j},\varphi_n)$-invariant.  This is exactly the weak stability used
in Section~6; it does not silently strengthen the stage-zero definition
by adding invariance as an extra conjunct.
\end{definition}
